# QA Domain — Research

## Overview

Research QA evaluates studies, analyses, and investigative documents.

## Axes

### 1. Hypothesis
- Stated clearly? Falsifiable?

### 2. Method
- Appropriate for the question?

### 3. Bias
- Selection, confirmation, or survivorship bias addressed?

### 4. Missing data
- Gaps acknowledged?

### 5. Internal / external validity
- Conclusions supported within scope?

### 6. Reproducibility
- Another analyst could follow the same path?

### 7. Over-strong conclusions
- Claims exceed evidence?

## Severity grid (research)

| Severity | Criterion |
|----------|-----------|
| `critical` | Fabricated or misrepresented data ; conclusion contradicts evidence |
| `warning` | Method mismatch, unacknowledged bias, missing key data |
| `info` | Additional source, clearer limitation statement |
