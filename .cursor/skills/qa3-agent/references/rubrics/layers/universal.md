# Universal layer — all passes

Always loaded on every worker pass, **without exception** (except coverage failure before business audit).

## Axis 1: Intent / deliverable alignment

Does the deliverable fulfill what was asked? Are scope boundaries respected?

## Axis 2: Internal coherence

No contradictions within the deliverable. Terminology and claims consistent.

## Axis 3: Completeness

Required sections, steps, or artifacts present. No critical gaps for the stated audience.

## Axis 4: Evidence / traceability

Claims backed by references, tests, or explicit rationale. Decisions traceable.

## Axis 5: Testability / verifiability

Requirements and behaviors can be checked objectively. Acceptance criteria measurable where applicable.

## Axis 6: Risks / failure modes

Failure scenarios identified. Mitigations or explicit acceptance of residual risk.

## Axis 7: Decision / arbitration

Trade-offs documented. Open choices flagged. Reversibility considered.

## Severity grid (universal)

| Severity | Criterion |
|----------|-----------|
| `critical` | Blocks safe or correct use ; fundamental contract breach |
| `warning` | Significant gap, ambiguity, or unmitigated risk |
| `info` | Clarity, structure, or documentation improvement |
