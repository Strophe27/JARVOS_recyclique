# QA Domain — Text

## Overview

Text QA evaluates prose deliverables: essays, articles, narratives, marketing copy, long-form explanations.

## Axes

### 1. Central thesis
- Is there a clear main point?
- Does every section support or advance it?

### 2. Argumentative progression
- Logical flow from introduction to conclusion?
- Transitions between sections?

### 3. Density / redundancy
- Repetition without added value?
- Sections that could be merged or cut?

### 4. Term precision
- Key terms defined and used consistently?
- Ambiguous pronouns or referents?

### 5. Tone / audience
- Tone matches intended reader?
- Jargon level appropriate?

### 6. Weak passages
- Sections that lose clarity or momentum?
- Unsupported claims?

### 7. Unfulfilled promises
- Headings or intros that promise content not delivered?

## Severity grid (text)

| Severity | Criterion |
|----------|-----------|
| `critical` | Misleading or harmful claim ; fundamental logical flaw |
| `warning` | Significant ambiguity, unsupported assertion, audience mismatch |
| `info` | Wording, structure, or example improvement |
