# Calibrated examples — document

## P0 — example 1

An installation procedure gives a destructive or dangerous command without prerequisites or warning.

**Why P0**: the document can break a user system.

## P0 — example 2

The document claims a service is compliant / secure while describing itself an absence of authentication or access control.

**Why P0**: dangerous contradiction on a critical point.

## P1 — example 1

The document omits prerequisites needed to execute the procedure.

**Why P1**: reader may be blocked, but main content remains recoverable.

## P1 — example 2

Two sections use different names for the same component without explaining equivalence.

**Why P1**: significant ambiguity, source of error.

## Info

Adding a summary table at the start of the document would improve navigation.

**Why Info**: readability improvement.
